# ARM64 Raspberry Pi 4 From Zero

A step-by-step journey from a single ARM64 assembly source file to a bare-metal program running on a Raspberry Pi 4.

## Stages

1. Assembly source to object file
2. Calling ARM64 assembly from C
3. Creating a custom entry point
4. Running the first bare-metal program on Raspberry Pi 4

Each stage introduces only one major new concept.
